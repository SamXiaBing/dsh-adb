## 二、文案（约 400 字）

**标题**：《把车机变成 AI 的"外设"：一个让 agent 自己敲 adb 的 DSH 插件》

实车联调的日常：bug 单来了，先连设备、拉日志、抓性能、装新版，一套 adb 命令敲下来，半小时没了。最耗时的从来不是问题本身，是这些重复操作——尤其在座舱 3D HMI，SR 的 bug 单永远是全车最多的，这我太熟了。

我把它们做成了 DeepSeek Harness 插件 dsh-adb。装上之后，agent 自己就能干四件事：查设备，adb_devices 一眼看到台架在不在线；翻日志，按 tag/级别/关键字过滤，还能挂后台持续采集，边查边收；装包传文件，apk 直接装，日志随手拉；查性能，内存、帧率、卡顿率一键结构化快照，提测前对比不要太方便。

和让 agent 裸敲 bash 最大的差别：输出是结构化的，错误是语义化的，长任务能挂后台，多设备不串台——联调里那些"脏活"，终于可以一句话交代出去，agent 查完还能整理成表给我看。

安装就一行：dsh plugin add dsh-adb。

已经发布到 npm，三份社区清单全部收录，7 个工具全在真机台架实测过，中间还修掉四个只有真机才能暴露的 bug。做车机、安卓、嵌入式调试的同行，欢迎来玩，也欢迎提需求。
